# Gustul din Căruță (gustuldincaruta.ro)

Website modern de prezentare și configurator interactiv de oferte pentru **Gustul din Căruță** — concept gastronomic tradițional și gourmet pentru nunți, botezuri și evenimente speciale.

## Caracteristici & Funcționalități

- **Design Cald & Festiv**: Paletă de culori luminoasă (alb, ivoire, accente de chihlimbar și lemn masiv) cu contrast ridicat pentru lizibilitate maximă (standard WCAG AAA).
- **Hero Interactiv**: Card translucid *frosted glass* cu imagine de fundal dinamică și butoane de apel la acțiune (CTA) imediate.
- **Configurator Ofertă WhatsApp**:
  - Pas 1: Tip de eveniment (Nuntă, Botez, Aniversare, Corporate).
  - Pas 2: Număr estimat de invitați (slider interactiv, implicit 280 persoane).
  - Pas 3: Selector pentru dată exactă (calendar nativ) sau opțiune de sezon.
  - Pas 4: Selecție servicii (Căruță tradițională, Jamon Iberico Live Carving, Proțap & Grill).
  - Generare automată a mesajului complet formatat pe WhatsApp pentru conversie directă.
- **Prezentare Meniu & Pachete**: Structură clară pentru pachetele de servicii (Boieresc, Regal Jamon, Imperial Complet).
- **Galerie Foto Compactă**: Bloc uniform de fotografii apetisante cu efecte vizuale la hover și legătură directă către pagina oficială de Facebook.
- **Recenzii & Întrebări Frecvente (FAQ)**: Acordeon interactiv și testimoniale de la miri și organizatori.
- **Butoane WhatsApp Flotante & Buton Scroll to Top**.

## Tehnologii Utilizate

- **HTML5 Semantic**
- **Tailwind CSS (CDN)**
- **Lucide Icons**
- **Google Fonts** (*Playfair Display*, *Cormorant Garamond*, *Plus Jakarta Sans*)
- **Vanilla JavaScript** (fără dependențe greoaie, încărcare ultrarapidă)

## Rulare Locală

Proiectul poate fi deschis direct în orice browser web sau servit local printr-un server web (Apache, Nginx, Live Server):
```bash
# Deschidere directă
start index.html
```
